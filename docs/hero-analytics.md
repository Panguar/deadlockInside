# Статистика героев API

`GET /api/v1/players/{account_id}/stats` считает показатели по матчам, уже загруженным в PostgreSQL. Фильтры `hero_id`, `from` и `to` совпадают с фильтрами истории; начало периода включается, конец исключается. `sample_size` — число матчей в выборке, `decided_matches` — матчи с исходом 1 или 2, а победой считается только исход 1. Неизвестные исходы не входят в win rate.

KDA считается как сумма убийств и ассистов, делённая на большую из величин: сумма смертей и 1. Если в матче отсутствует хотя бы один компонент K/D/A, этот матч не входит в KDA; `kda_sample_size` показывает размер этой подвыборки. Пустой знаменатель win rate и пустая выборка KDA возвращают `null`.

`GET /api/v1/heroes` и `GET /api/v1/heroes/{hero_id}` читают последний успешно загруженный справочник. `GET /api/v1/heroes/stats` читает снимок с точно совпадающей комбинацией периода, bucket и фильтров среднего ранга матча. `min_average_badge` и `max_average_badge` принимают значения от 0 до 65535 и фильтруют средний badge матча, а не личный ранг игрока. Все ID в JSON — строки. Ответы используют общий `data`/`meta`; `meta.sample_size` — сумма числа матчей в исходных bucket-записях, `updated_at` — время получения, `stale` — признак устаревания.

Без `from` и `to` аналитика использует последние 30 полных дней UTC. Для пользовательского периода нужно передать обе границы с часовым поясом; после приведения к UTC границы должны совпадать с началом часа, а период не должен превышать 31 день. Для границ в полночь используется bucket дня, иначе bucket часа. Поставщик включает округлённую верхнюю границу, поэтому приложение удаляет строки с bucket `>= to` после ответа. Снимок хранит фактические границы, bucket и фильтры; запросы с другими параметрами не используют его. Размер ответа поставщика ограничен 64 MiB.

Обновление справочника выполняется при запуске Celery worker и далее раз в сутки; агрегаты загружаются при первом запуске и затем раз в час. Запрос к отсутствующему или устаревшему фильтру ставит фоновое задание с дедупликацией в Redis. Маршрут не ждёт внешний запрос: при отсутствии снимка он возвращает 503 с сообщением, что обновление поставлено в очередь; при наличии устаревшего снимка сразу возвращает его с `stale=true`. Частота чтения глобальной аналитики ограничена 30 запросами в минуту на IP.

Глобальный ответ включает число матчей, победы, поражения, win rate и суммарный KDA, если все его исходные bucket-строки содержат K/D/A. `kda_sample_size` сообщает число матчей в строках, использованных для KDA. Счётчики контр-подборов и предметные сборки пока не включены: текущий контракт не подтверждает точность временной фильтрации этих данных, а содержимое fixture не описывает полный период. Процент выбора не рассчитывается без подтверждённого знаменателя.
