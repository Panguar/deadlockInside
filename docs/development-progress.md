## Этап 5 — 19 октября 2026 года

Реализованы личные расчёты и GET players/{id}/stats с общими фильтрами истории: win rate по известным исходам, KDA по суммам, nullable результат при отсутствии данных, kda_sample_size для неполной выборки. Реализованы каталог героев, отдельный герой, глобальные агрегаты и immutable снимки с происхождением, фильтрами, размером выборки и временем получения.

Решение по источнику: глобальный интервал ограничен 31 днём и границами UTC-часа; по умолчанию последние 30 полных UTC-дней. Day/hour buckets исключают строку на верхней границе, сохраняя [from,to) несмотря на включительную округлённую границу upstream. Личные интервалы остаются точными. Global sample_size суммирует наблюдения героев, не обещает число уникальных матчей. Неподтверждённые процент выбора, содержимое сборок и точные фильтрованные противостояния не выдумываются; подробности в docs/hero-analytics.md.

Каталог имеет собственную запись обновления и membership, поэтому заглушки из матчей не подменяют справочник, а пустой результат сохраняет корректную свежесть. Worker обновляет каталог при старте/раз в сутки, аналитику при старте/раз в час. Для нестандартных периода и среднего ранга матча HTTP-запрос ограниченно ставит дедуплицированное фоновое обновление; worker валидирует фильтры и сохраняет снимок того же ключа. Старый совпадающий снимок доступен со stale=true; отсутствие — 503 до готовности. Проверка UTC-overflow возвращает 422.

TDD/ревью: исходные расчёты и маршруты прошли RED→GREEN. Полный набор 99 тестов прошёл дважды подряд на одной БД. Ревью выявило отсутствие пути загрузки нестандартных фильтров/ранга и UTC-overflow; добавлены регрессии и исправления. Финальный набор — 103 passed, независимое ревью APPROVE. На отдельной deadlock_stage5_migrations_test выполнен upgrade → downgrade → upgrade → alembic check без расхождений.

Проверка реального Docker: Compose пересобран, API/PostgreSQL/Redis healthy, worker и beat запущены. Автоматически загружены 43 героя и глобальный снимок из настоящего источника. Проверен нестандартный интервал 17–18 октября с min_average_badge=50/max_average_badge=100: первый HTTP 503 поставил задание, последующий HTTP 200 вернул совпадающий свежий снимок. Массовой загрузки игроков не было.
