# Deadlock Inside

Сайт статистики Deadlock с интерфейсом на Next.js и отдельным бэкендом на Python. Референс пользовательских сценариев — [Porofessor](https://porofessor.gg/).

Проект находится на этапе проектирования; приложение ещё не реализовано.
